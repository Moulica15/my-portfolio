# PhishBlock Documentation

## Introduction

PhishBlock is a phishing detection system developed using machine learning and Flask.

The system analyzes URLs and predicts whether a website is legitimate or malicious.



## Objectives

- Detect phishing URLs
- Improve online safety
- Apply machine learning in cybersecurity



## Technologies Used

- Python
- Flask
- Scikit-learn
- HTML/CSS



## Working Principle

1. User enters URL
2. Features are extracted
3. ML model analyzes the URL
4. Prediction result is displayed



## Future Improvements

- Browser extension integration
- Real-time threat database
- Advanced ML models
